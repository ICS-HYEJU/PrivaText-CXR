# MIMIC-CXR-JPG p10-p12 manifests

Generated by `src/Data/prepare_mimic_jpg.py` with seed 42,
`--no_finding_ratio 2.0`, and `--verify_images`.

- train: p10/p11 official `train`
- validation: p10/p11 official `validate`
- excluded: p10/p11 official `test`
- test: all usable p12 rows
- balancing: single-positive `No Finding` is changed only in train

Pass `ldm_dp_manifest.csv.gz` to finetuning:

```bash
/opt/conda/bin/python src/LDM_dp_finetune.py \
  --root_path /storage/hjchoi/physionet.org/files/mimic-cxr/2.1.0 \
  --manifest_csv data_manifests/mimic_p10_p12/ldm_dp_manifest.csv.gz \
  --split train
```

`split_summary.json` records source checksums, counts, leakage checks, and
decode verification. `class_distribution.csv` reports single-positive
image/study/patient counts. Sufficiency uses distinct patients:
`sufficient >= 500`, `limited >= 100`, otherwise `insufficient`.
