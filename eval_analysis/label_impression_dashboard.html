Best model

05 · goal 1
Verdict

LABEL+IMPRESSION · ε = 8.591

Best on every metric family this evaluation's own guidance ranks as most trustworthy, while running statistically even (within ~1%) with the other two on the less reliable label‑AUROC and pixel‑proxy metrics.

  • Best FID (2.271) and best FDS on all three variants (symmetric, hallucination, mode‑collapse) of any checkpoint tested.
  • Best CLIP zero‑shot diagnosis gap and ratio — images are the most correctly diagnosable by an independent reader.
  • Beats the legacy text format at the same privacy budget, and beats its own tighter‑budget sibling on every reliable metric.
  • LI_eps1 (tighter privacy) and plain_eps10 (legacy format) remain reasonable choices for their respective constraints, but neither overtakes LI_eps10 on the metrics that matter most for judging generation quality.

Methodology & caveats

07 · notes

Training data

MIMIC‑CXR v2.1.0 train split — 31,553 images (legacy text) / 29,888 images (LABEL+IMPRESSION, after dropping 1,665 studies with no positive CheXpert label). Only p10/p11 patient‑prefix DICOMs are downloaded locally, so test (the real reference set used throughout) is capped at 361 images — unrelated to training‑set size.

A bug caught mid‑analysis

All three checkpoints are LoRA fine‑tunes. The first generation pass used --dp_ckpt only; without --lora_ckpt, load_state_dict(strict=False) silently drops all 256 LoRA‑delta tensors, so every model fell back to the un‑fine‑tuned pretrained base — caught via byte‑identical generated images across different checkpoints. Fixed by passing the same file as both --dp_ckpt and --lora_ckpt, then re‑verified outputs diverge and every run logs lora_keys=256 missing=0 unexpected=0.

Scope decisions

roent_clip (RoentGen‑style retrieval), present in an older reference run, is omitted — its implementing module doesn't exist in git history on any branch, and reimplementing it was explicitly descoped. CLIP‑based metrics were pinned to cuda:0 (MedCLIP appears to hardcode that device internally). CLIP text scoring used FINDINGS/IMPRESSION for all three models, independent of each model's own training‑time conditioning format, to keep the CLIP comparison apples‑to‑apples.
